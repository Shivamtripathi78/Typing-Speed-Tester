# Typing Speed Tester

Typing Speed Tester is a responsive web application that helps users measure and improve their typing speed, accuracy, and consistency.

## Features

- Real-time words-per-minute calculation
- Typing accuracy percentage
- Incorrect character tracking
- 30-second, 60-second, and 120-second tests
- Random typing passages
- Visual feedback for correct and incorrect characters
- Personal best tracking
- Responsive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Local Storage API

## Getting Started

1. Clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.

## How to Use

1. Select a test duration.
2. Click the typing area.
3. Start typing the displayed passage.
4. Monitor your WPM, accuracy, remaining time, and errors.
5. Review your final results.

## Data Storage

Your personal best is stored locally in your browser. It is not synchronized across devices.
